# datacooper-tug-share frontend-slides remake

Single-file HTML presentation remake of the Datacooper TUG Share talk, built in the spirit of `zarazhangrui/frontend-slides`.

## Preview

Open `index.html` directly in a browser, or run a local static server:

```powershell
python -m http.server 3045
```

Then visit `http://localhost:3045/`.
