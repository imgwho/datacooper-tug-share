Positioning
03 / Scope
Role in the workflow

Tableau sits in the middle of a much larger delivery system.

cwprep mostly targets data preparation, while cwtwb targets workbook generation, validation, and orchestration.

Flow

Data Input

Databases, Excel, CSV, APIs

Data Prep

Clean, join, transform, aggregate

Tableau

Model, calculate, lay out, visualize

Distribution

Publish, review, iterate

Feedback

Revise data, improve design, redeploy

Why build these tools
04 / Pain

The pain is mechanical repetition.

The hardest part of Tableau work is often not insight generation. It is the repeated execution of small, structured tasks.

Dragging fields again and again

Many dashboards differ only slightly, yet the assembly work repeats manually.

Rebuilding layouts

KPI zones, headers, and spacing logic are copied over and over.

Checking file validity

Teams still waste time confirming whether a workbook can open and publish correctly.

Migrating to new data sources

Schema changes often trigger expensive manual rework rather than targeted replacement.

Low repeatability

Important logic lives in personal habits instead of a visible, reviewable system.

Slow collaboration

Without engineering structure, BI delivery stays hard to audit, scale, and hand off.

cwprep
05 / Data Flow
One-line description

Describe a Prep flow in natural language, generate a usable .tfl / .tflx.

  • Text-to-PrepFlow instead of GUI-only assembly
  • MCP integration for Claude, Cursor, Gemini, and others
  • Supports operations such as join, union, pivot, filtering, and packaging
  • Can translate flows into SQL for reviewability
Why it matters

Efficiency

Automates repetitive flow construction that usually lives inside Tableau Prep clicks.

Consistency

Encodes common cleaning logic in reusable instructions instead of ad hoc manual steps.

Engineering fit

Moves data preparation closer to scripting, versioning, and automated delivery workflows.

cwtwb
06 / Workbook
One-line description

Generate, validate, and refactor Tableau workbooks as deterministic artifacts.

  • Builds charts, dashboards, calculations, and layouts from code or agent workflows
  • Supports validation, migration, TWBX packaging, and structured save flows
  • Works as both Python SDK and MCP tool surface
  • Targets engineering-grade repeatability rather than one-off manual output
Where it wins

Dashboard orchestration

Not just worksheets. It handles layout, dependencies, actions, and packaging.

Validation

Structural checks, XSD validation, and later cloud semantic validation reduce delivery risk.

Migration and reuse

Makes repeated rebuilds and datasource changes far less manual than the normal Tableau path.

datacooper.com
07 / Product
Direction

Turn engineering capability into a product, not just a local script collection.

The longer-term goal is not to mirror commands in a browser, but to make common BI actions feel immediate, guided, and easier to access.

Current prototype direction

Layout extraction

Parse dashboard layout structures and export them into JSON or structured representations.

KPI replication

Clone KPI worksheet structures and swap only the target metric instead of rebuilding from scratch.

Online usage

Lower the barrier so users can benefit from the capability without setting up a full local environment.

Code becomes a tool

The backend stays engineering-heavy, but the front-end experience becomes calmer and easier to adopt.

08 / Timeline
The core arc

From TWB prototype to AI-oriented workbook engineering toolkit.

The project expanded rapidly across charting, validation, MCP workflows, and guided authoring, then deliberately converged back toward a more stable core.

2026-02-27 → 2026-02-28

2026-03-02 → 2026-03-06
Productization

2026-03-06 → 2026-03-17
Agent-first expansion
Skills, capability catalogs, richer chart APIs, and styling systems make the toolkit much more AI-friendly.
2026-03-17 → 2026-06-27
Validation + convergence
TWBX, XSD, cloud validation, and later the removal of dormant guided authoring sharpen the final product boundary.
