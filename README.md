# DataCooper TUG Share

这是一个使用 [Slidev](https://sli.dev/) 制作的中英文双语演示文稿。

## 演示地址

- **中文版**: [https://imgwho.github.io/datacooper-tug-share/](https://imgwho.github.io/datacooper-tug-share/)
- **英文版**: [https://imgwho.github.io/datacooper-tug-share/en/](https://imgwho.github.io/datacooper-tug-share/en/)

## 本地开发

安装依赖：

```bash
pnpm install
```

启动中文版：

```bash
pnpm run dev
```

启动英文版：

```bash
pnpm run dev:en
```

## 部署

本项目通过 GitHub Actions 自动部署到 GitHub Pages。任何推送到 `main` 分支的更改都会自动触发构建。
